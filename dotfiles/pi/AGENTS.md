# Rules

Rule files live in `~/.pi/agent/rules/`. Read a rule before doing the work it covers.

Always apply:

- `rules/context-budget.md`: keep tool output and file reads small
- `rules/pr-workflow.md`: push, PR, and branch safety
- `rules/artifact-readability.md`: writing durable documents
- `rules/communication.md`: replies, explanations, and PR descriptions

Apply when editing matching files:

- `rules/style.md`, `rules/comment-quality.md`: code files (`ts`, `js`, `py`, `go`, `rs`, `sh`, `lua`)
- `rules/test-quality.md`: test and spec files
- `rules/rust.md`: `*.rs` files
- `rules/skill-editing.md`: `skills/**/*.md`
